Existing clients

The caller id must match a contact and the spoken name must match that contact (or an alias). The agent then hears open matters with stage, next event, next task, invoice balance and the date of the last update. Never note text, documents, trust balances or other clients.

Reminder calls

Run python -m app.cli voice_reminders once a day. One call per event per client, saying the firm name, event title, date and time. No case detail. {% if not twilio %}Twilio is not configured, so the job only logs what it would say.{% endif %}

Attorney PINs

The memo line recognises attorneys by caller id plus a 4 to 6 digit PIN, set on each user's page. Five wrong PINs from a number lock it for an hour.

API reference

Base URL {{ base }}/api/v1. Send Authorization: Bearer <token> on every request. Responses are JSON. Errors look like {"error": "...", "status": 401}: 401 bad token, 403 missing scope, 404 not found, 429 more than {{ rate_limit }} calls in a minute. Money is integer cents; dates are YYYY-MM-DD.

MethodPathScopeNotes
GET/mereadThe token's user, scopes, firm name and any running timer.
GET/matters?q=&status=readq matches number, name, case number or client. status defaults to open; use all, pending or closed.
GET/matters/<id>readOne matter with unbilled totals.
GET/contacts?q=readName or email search, 50 results.
GET/time?matter_id=&from=&to=&user_id=readNewest 200 entries.
POST/timewriteJSON or form: matter_id, minutes or hours (1.5, 1:30, 90m), description, date, billable. Rate comes from the matter or user.
GET/timerreadThe user's running timer or null.
POST/timer/startwritematter_id, description. 409 if one is already running.
POST/timer/stopwriteOptional matter_id, description. Creates a time entry rounded up to 6 minutes.
GET/invoices?status=readstatus: open (sent, viewed, partial), draft, paid, void, all.
GET/tasks?due=today|overdue|week&mine=1readOpen tasks.

Example: curl -H "Authorization: Bearer coil_..." "{{ base }}/api/v1/matters?q=alvarez". The Chrome extension in the repository's extension/ folder uses these endpoints; see its README for load-unpacked steps.

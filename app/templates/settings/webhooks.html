How deliveries work

Each event is POSTed as JSON {"event": "invoice.sent", "created_at": "...", "data": {...}} with headers X-Coil-Event, X-Coil-Delivery and X-Coil-Signature: sha256=<hmac>. The signature is an HMAC-SHA256 of the raw body using the webhook's secret; verify it before trusting the payload.

A 2xx response counts as delivered. Anything else, or a timeout after 5 seconds, is retried by python -m app.cli webhooks (run it from cron every few minutes) with backoff at 1, 5, 30, 120 and 720 minutes, up to 5 attempts. You can also retry a delivery from the list below.

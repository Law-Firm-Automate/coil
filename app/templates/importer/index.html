How to export from Clio, MyCase, PracticePanther

Bring your practice across one file at a time. Export each list from the old system as a CSV, upload it here, check the column mapping on the preview page, then import. Do them in this order, because later files link to earlier ones: contacts, matters, time and expenses, bills, trust, tasks, calendar, notes, documents.

Coil remembers the old system's id for every row it imports. Uploading a file a second time updates the records it already created instead of making duplicates, so you can fix a spreadsheet and re-upload it as often as you like. An import never deletes anything.

Picks the column names to look for. Generic CSV works for anything else; you map the columns by hand on the preview page.

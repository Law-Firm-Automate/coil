Switching from another system

Go to imports

The short version

  1. Export each list from the old system as CSV. Pick "all columns" wherever that is offered; extra columns are harmless and ids make re-imports exact.
  2. Upload the files on the imports page in this order: contacts, matters, time and expenses, bills, trust, tasks, calendar, notes, documents. Each file links to the ones before it.
  3. On each preview page check the column mapping and the first twenty rows, then import. Rows with problems are listed with a downloadable CSV; fix those rows and upload that smaller file. Nothing is duplicated on a second pass.
  4. Before the trust file, add opening balances for any client whose export does not go back to the first deposit.
  5. Keep the old system in read-only mode for a month. Time already billed there arrives as non-billable so it cannot be billed twice.

Clio Manage

Contacts: Contacts, scroll to the bottom, Export, CSV, "all columns". Person and company rows share one file; the Type column tells them apart. Several email and phone columns are fine, Coil takes the first that is filled.

Matters: Matters, Export, CSV, all columns. Coil uses Client ID to link, then Client Name. Custom Number or Display Number becomes the Coil matter number when it is free. Status Open, Pending and Closed carry over.

Time and expenses: Activities, quick filter All, clear the date range, Export, CSV, all available columns. The Type column (TimeEntry, ExpenseEntry, HardCostEntry) decides which each row becomes. Quantity is decimal hours. Billed or Bill state marks rows already on a Clio bill.

Bills: Billing, All bills, Export, CSV. Coil reads Bill #, Client, Matter, Issued, Due, Total, Paid or Balance, and State.

Trust: Accounts, open the trust account, Export transactions, CSV, or the Transactions tab on a client. Funds In and Funds Out columns, or a signed Amount, both work. Add opening balances first if the date range does not start at the first deposit.

Tasks, calendar, notes: Tasks page Export, Calendar export (Excel Ready CSV on the Exports page), Matter Notes export on the same page.

Documents: Documents, download per matter, put each matter's files in a folder named after the matter number or name, ZIP the folders (under 200 MB per ZIP).

MyCase

Everything at once: Settings, Import/Export, Full Data Backup. You get a ZIP with one CSV per area (contacts, cases, time and expense entries, invoices, trust, tasks, calendar, notes). Upload each CSV to the matching card.

Contacts and cases only: the same page has separate Contacts and Cases exports; choose CSV and "all cases".

Cases use "Case/Matter Name", "Number", "Case Closed" (TRUE means closed), "Lead Attorney", "SOL Date". Time entries use Hours. Coil links entries to cases by the case name or number.

Documents: download from each case, folder per case name, ZIP.

PracticePanther

First set Settings, Company Settings: Contact display "First M Last", Matter display "Number-MatterName", Users "First M Last", so names in the exports line up.

Contacts: Contacts, filter Any User, All Time, Export to Excel, then save as CSV.

Matters: Matters, Any User, Any Status, All Time, Choose Columns (tick everything), Export. Coil reads Matter number, Matter name, Linked client, Assigned user, Status.

Time and expenses: Time Entries and Expenses (under More), Any User, Any Status, All Time, all columns, Export. Status Billed means already invoiced; NotBillable stays non-billable. Assigned To is the user's email.

Invoices, trust, tasks, events, notes: each has its own list under Billing or Activities with the same filter-then-export pattern.

Any other system (Generic CSV)

Any CSV with a header row works. Coil guesses columns from common names (Name, Email, Matter, Date, Hours, Amount ...) and lets you assign the rest on the preview page. Dates can be YYYY-MM-DD or MM/DD/YYYY. Hours can be 1.5, 1:30, or 1h 30m. Money can have $ and commas. Include an id column from the old system if you have one; that is what makes a second upload update instead of duplicate.
